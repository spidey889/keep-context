Get connected

A small server.
Your own account.

Install uv and Python 3.11+, then open a terminal. Setup includes one manual Google sign-in step; the guide walks you through it.

Read the sign-in guide →
  1. 1

    Connect Google Keep

    git clone https://github.com/spidey889/keep-context.git
cd keep-context
uv sync --locked
uv run keep-context connect
uv run keep-context doctor

    Save the separate connection password you choose. Google credentials stay in your OS vault.

  2. 2

    Start the server

    Install cloudflared. On Windows:

    winget install -e --id Cloudflare.cloudflared
    uv run keep-context serve --tunnel

    Keep the terminal running. Copy the printed HTTPS URL ending in /mcp.

  3. 3

    Add it to ChatGPT

    Open Plugins → Add → Create custom MCP server. Paste your server URL, choose OAuth with dynamic client registration, and approve using your connection password.

    Select Keep Context with @ in a new chat. Then ask about your notes.

A few things to know.

Your notes stay in Keep

The server holds an in-memory copy for reading, with no notes database. Notes you ask ChatGPT to read are shared with ChatGPT.

Read access, by design

It can search and read notes, labels and checklists. It cannot create, edit or delete them. One Google account per server.

Simple, with honest limits

Consumer Keep access uses an unofficial API. Search is keyword based; prose TODO detection is a best effort. Images, audio and reminders are outside this MVP.

Keep your server running

The temporary URL changes when you restart the tunnel. For everyday use, the setup guide covers a stable HTTPS address.
